打开 [index.html](index.html) 即可玩。请保留同目录的 CSS、三个 JS 文件和 NOTICE.txt，离线无需服务器或安装。

拖动下方把手改变球路，松手一起发射。最多接 4 颗，标准局 90 秒；首次有一球、两球热身，设置可选不限时练习。键盘按住空格抓取，方向键调整，松开空格发射；Shift 细调，Backspace 取消，Esc 暂停。支持触摸。

暂停、取消和同局重试均可用。滚动阅读说明会暂停；设置和个人最佳只在当前浏览器保存，不自动上传。
