# 兜弹 / Scoop & Snap · 1905

打开 [index.html](index.html) 即可试玩。保留同目录全部文件，离线无需服务器、构建或安装。

鼠标或触摸按住建立锚点，拖过同形粒子，再拉到锚点下方松手发射。第一颗决定本兜形状，最多六颗。右键或“取消本兜”放回粒子。键盘方向键移动光标，空格切换按住 / 松开，C 取消，Esc 暂停。

首次先练三颗圆形，再选择 90 秒正式局或自由练习。实心预览点表示可送达，叉号表示失手。同局重玩保留来流；实验玩法与标准成绩分别记录。
